# Backend Development Complete Guide — Node.js + Express.js

## Welcome

This is a **complete backend development learning guide** using **Node.js** and **Express.js**. It starts from the very basics (how the internet works) and goes all the way to advanced topics like microservices, scaling, and production deployment.

Each phase is a separate Markdown file. Work through them **in order** — each builds on the previous one.

## Prerequisites

- Basic JavaScript knowledge (variables, functions, arrays, objects, promises, async/await)
- Node.js installed on your machine
- A code editor (VS Code recommended)
- Terminal / command line basics
- Basic understanding of what a website/web app is

---

## How to Use This Guide

1. **Read each phase in order** — they build on each other
2. **Type out every code example** — don't copy-paste, build muscle memory
3. **Build the mini-projects** suggested in each phase
4. **Experiment** — change code, break things, fix them
5. **Take notes** — write down concepts in your own words

---

## Tech Stack Covered

- **Runtime:** Node.js
- **Framework:** Express.js
- **Databases:** MongoDB (Mongoose), PostgreSQL (basic), Redis
- **Auth:** JWT, Sessions, Cookies, OAuth 2.0
- **Testing:** Jest, Supertest
- **Real-time:** Socket.io
- **Queues:** BullMQ
- **Deployment:** Docker, PM2, Nginx, CI/CD
- **Cloud:** AWS basics, Railway, Render
