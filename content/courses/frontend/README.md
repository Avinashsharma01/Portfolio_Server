# Frontend Development Complete Guide — HTML, CSS, JavaScript & React

## Welcome

This is a **complete frontend development learning guide** covering **HTML, CSS, JavaScript, and React**. It starts from the very basics (how the browser works) and goes all the way to advanced topics like performance optimization, accessibility, TypeScript, and production deployment.

Each phase is a separate Markdown file. Work through them **in order** — each builds on the previous one.

## Prerequisites

- Basic computer literacy (files, folders, using a browser)
- A text editor (VS Code recommended)
- A modern web browser (Chrome or Firefox with DevTools)
- Willingness to type out code and experiment
- No prior programming experience needed — Phase 01 starts from scratch

---

## How to Use This Guide

1. **Read each phase in order** — they build on each other
2. **Type out every code example** — don't copy-paste, build muscle memory
3. **Build the mini-projects** suggested in each phase
4. **Experiment** — change code, break things, fix them
5. **Use browser DevTools** — inspect elements, debug JavaScript, watch network requests
6. **Take notes** — write down concepts in your own words

---

## Tech Stack Covered

- **Markup:** HTML5 (semantic, forms, media, accessibility)
- **Styling:** CSS3, Flexbox, Grid, Animations, CSS Variables, CSS Modules
- **Scripting:** JavaScript ES6+, DOM manipulation, async/await, Fetch API
- **Framework:** React (components, hooks, state, routing)
- **Type Safety:** TypeScript
- **Testing:** Jest, React Testing Library, Cypress
- **Build Tools:** Vite, Webpack basics, npm/pnpm
- **Performance:** Lighthouse, Core Web Vitals, lazy loading, code splitting
- **Deployment:** Vercel, Netlify, GitHub Pages, CI/CD pipelines
